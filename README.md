# Apex House

A concept website for a private automotive club combining a members lounge,
climate-controlled collector car storage, workshop access, events, and
concierge vehicle care.

## Included

- Responsive premium landing page
- Modern automotive-club hero artwork
- Lounge, workshop, event, and storage positioning
- Silver, Gold, and Platinum membership concepts
- Monthly and annual pricing interaction
- Tier-aware private tour inquiry modal
- Mobile navigation and responsive layouts

## Tech Stack

- Next.js
- React
- TypeScript
- Project styling in `app/globals.css`

## Run Locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Notes

- Apex House is a working concept name.
- Membership prices and benefits are placeholders for business validation.
- Vehicle residency is positioned as a separate monthly charge.
- The inquiry form is currently a front-end prototype and does not send data.
